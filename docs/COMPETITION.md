## 二、作品说明（可直接粘贴）

### 1. 团队 / 个人介绍

独立开发者个人参赛，独立完成全部产品设计、交互设计、前端开发与测试工作。
本项目为原创作品：所有图形元素（图标、封面）由 Python 脚本绘制生成，
五类助眠音频由 Web Audio API 实时合成，**未使用任何第三方版权素材**，
不存在知识产权风险。

### 2. 创意名称 + 创意介绍

**创意名称：熄灯早睡（Lights Out）**

**动机与灵感来源**：我自己就是「知道熬夜有害、却每天刷手机到凌晨两点」的那类人。
我试过市面上几乎所有主流睡眠 App，发现它们都停留在「提醒」层面——而提醒，
恰恰是意志力最薄弱的时刻最容易被划掉的东西。真正缺的不是动机，而是
**在动机失效之后仍然生效的机制**。后来我想起童年那根拉灯绳：手一拉，灯就灭，
没有商量的余地。这个动作本身就是一种不容置疑的仪式。

**一句话产品形态**：一个到点自动全屏接管设备、把手机变成一盏熄了灯的黑屏界面的
**Web / PWA 智能应用**。

### 3. 目标用户及痛点

**目标用户**：18–30 岁的学生与职场新人，有明确的早睡意愿但自控力较弱、长期受熬夜困扰。

**典型场景**：晚上 11 点躺在床上，告诉自己「再看十分钟就睡」；再抬头已经是凌晨两点。
第二天疲惫、愧疚，暗下决心今晚一定早睡；到了晚上，同样的循环再来一遍。

**具体痛点**：
1. 短视频与游戏的即时反馈，远远强于「早点睡」的远期收益，纯靠自控必然失败；
2. 现有睡眠 App 只有提醒功能，可被随手划掉或跳过，没有任何阻断能力；
3. 缺少外部约束，睡前刷手机的时间不断向后漂移，睡眠时长持续被压缩。

### 4. 功能介绍

**用户如何使用**：首次打开完成三步设置——① 设定工作日 / 周末两套熄灯时段
（默认 23:00 – 次日 07:00，支持跨天）；② 选择提前提醒时长（10 / 15 / 30 分钟）；
③ 设置紧急解除密码。之后无需任何日常操作。

**到点会发生什么**：熄灯前 15 分钟弹出**不可关闭**的全屏倒计时预告；
时间一到，屏幕播放「拉灯绳灭灯」动画（约 1.5 秒）——灯绳被拉下、灯泡由亮渐灭、
画面同步暗下，进入纯黑的全屏熄灯界面。界面中央是实时时间与距离熄灯结束的剩余时长，
下方轮播熬夜危害科普与情绪安抚语句，**每条科普都可一键展开查看原始文献**。

**熄灯期间可以做什么**：
- 打开白名单应用。系统电话、短信不占额度；其它应用共用一个可自定义的总可用时长
  （上限 60 分钟），用完立即锁定；
- 开启雨声 / 溪流声 / 海浪声 / 篝火声 / 纯白噪音五类助眠音频，支持独立音量与定时关闭
  （全部实时合成，无音频素材）。

**如何退出**：正常退出是等到熄灯时段结束，播放「拉灯绳亮灯」动画后恢复正常使用；
紧急情况需**连续点击屏幕 5 次**、输入密码，并消耗**每周仅 2 次**的解除额度
（自然周周一 0 点重置）——把「破戒」从一个零成本的冲动，变成一个需要认真考虑的稀缺资源。

**特色与实际价值**：
1. **AI 创造的真实价值**：识别周五晚、周六晚、周日晚、假期前夜、假期最后一晚、
   调休上班日晚等场景，生成贴合当下处境的睡前文案。
   例如周五晚会说「明天就是周末了，今晚睡个好觉，周末好好放松」，
   假期最后一晚会说「这是假期的最后一晚，今晚睡好，明天收心会轻松很多」。
   这是固定文案库无论如何排列组合都做不到的「当下感」。
2. **真实的防绕过机制**：修改系统时间、切走再回来、刷新页面、按返回键，
   都会被立刻拽回熄灯界面，杜绝「卡 bug 逃逸」。检测到改时间时**不重置剩余时长**。
3. **零依赖、零构建、离线可用**：没有 npm 依赖、没有构建步骤、没有外部请求，
   断网也能进入熄灯界面——这一点对强制型工具至关重要，否则断网就成了最简单的绕过方式。
4. **数据可溯源**：界面上的每一条熬夜危害科普都绑定原始文献，可一键查看出处。
   我们坚持不写任何编造的统计数字。
5. **隐私优先**：所有设置与记录只存在用户本机，不上传服务器；
   AI 的 API Key 由用户自己保管，请求直接发往用户填写的接口地址。

**最终结果**：用户不需要在深夜和意志力搏斗——这个决策被提前到了白天清醒的时候完成。
