# 路线图

## V1.0（当前版本）

**已完成**

- 睡眠计划管理：工作日 / 周末双时段、跨天、提前预告、一键开关
- 强制熄灯模式：拉灯绳动画、全屏黑屏界面、白名单、紧急解除、每周额度
- 助眠音频：五类实时合成白噪音、定时关闭、独立音量
- AI 场景化文案：场景识别 + OpenAI 兼容接口 + 无 Key 降级
- 防绕过：时间篡改检测、后台切换拦截、刷新与返回键拦截、离线可用
- PWA：可安装、离线、standalone 全屏
- 核心逻辑单元测试 108 项
- 原生端骨架：Android（Kotlin）与桌面端（Avalonia）

**明确未做（诚实标注）**

- Web 端无法真正阻止用户打开其它 App（浏览器沙箱限制）
- Android 端、桌面端在当前开发环境未编译验证（缺少 SDK / 工具链）

## 长期方向

- **接入更多平台形态**：浏览器扩展（拦截特定站点）、macOS 菜单栏应用、智能手表联动
- **更聪明的场景识别**：结合天气、次日日程（需用户显式授权）调整文案与熄灯强度
- **可插拔的强制策略**：让用户组合不同的约束强度（如「渐进制裁」：本周超时次数越多，下周额度越少）
- **开放核心包**：把 `@xideng/core` 抽成可独立发布的 npm 包，供其它睡眠类应用复用

---

## 不做的事

以下方向明确不在计划内，避免产品走偏：

- **不做社交feed / 内容流** —— 目标用户的问题正是被信息流绑架，不应该再引入一个
- **不做社区排行 / 公开榜单** —— 睡眠是私事，公开比较会制造新的焦虑
- **不做付费墙** —— 核心功能永久免费；如未来有商业化，只会是可选的高级功能（如云端同步）
- **不上传任何用户数据** —— 包括「匿名统计」，因为「匿名」在实践中很难被验证
- **不给出医疗建议** —— 涉及睡眠障碍时只做引导就医，不做诊断
