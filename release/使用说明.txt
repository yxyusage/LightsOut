熄灯早睡 · Windows 桌面版（单文件 EXE）
=========================================

一、运行要求
  · Windows 10 / 11（64 位）
  · 需要已安装 .NET 10 Desktop Runtime
    （本机已装 .NET SDK 的可以直接运行；给其他电脑用时，
     需先安装：https://dotnet.microsoft.com/download/dotnet/10.0 的
     ".NET Desktop Runtime 10.x"）

二、启动与退出
  · 双击 Xideng.Desktop.exe 启动，会打开"设置窗口"
  · 关闭设置窗口后应用不退出，会最小化到系统托盘（右下角小图标）
  · 托盘右键菜单：打开设置 / 立即预览熄灯（12 秒）/ 退出
  · 左键单击托盘图标：打开设置窗口

三、日常使用流程
  1. 在设置窗口配置：
     - 睡眠计划（工作日/周末的开始与结束时间，默认 23:00–07:00）
     - 提前预告分钟数
     - 白名单应用（熄灯后可用的程序，共用总时长，上限 60 分钟）
     - 紧急解除密码（必须设置，否则熄灯后无法解除）
     - 开机自启（可选）
  2. 到点后全屏进入熄灯流程：
     - 先出现"拉绳"界面 —— 用鼠标按住绳头向下拖动，
       拉到最底部灯即熄灭；60 秒不拉也会自动熄灭
     - 随后进入黑屏熄灯界面：显示时间、剩余时长、助眠文案
     - 熄灯期间检测到非白名单程序抢焦点，会立即拉回熄灯窗口
  3. 紧急解除：熄灯界面内连续点击屏幕 5 次，输入密码即可解除
     （每周限 2 次，周一 0 点重置）

四、数据位置
  · 设置与用量记录保存在：%APPDATA%\xideng
  · 违规记录（改时间等）：%APPDATA%\xideng\violations.json

五、当前版本说明
  · 拉绳仪式：进入熄灯需亲手拉绳（或 60 秒自动熄灭）
  · 助眠音频：桌面端暂未内置白噪音（Web/PWA 端有），后续版本补齐
  · 单文件为 framework-dependent 模式，体积较大但无需解压；
    self-contained（免装运行时）版本待网络恢复后另行发布
