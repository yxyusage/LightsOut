# 交付前检查清单

> 复制这份清单，逐项打勾。**任何一项没验，都不算交付。**

## A. 合成与代码

- [ ] 每支片子是**独立工程**，根目录只有一个带 `data-composition-id` 的 HTML
- [ ] 根节点齐备：`data-composition-id` / `data-start="0"` / `data-duration` / `data-width` / `data-height` / `data-fps`
- [ ] `window.__timelines["<data-composition-id>"]` 注册了**唯一一条** `gsap.timeline({paused:true})`，且脚本末尾 `tl.seek(0)`
- [ ] `data-duration` == 片长；`退出动画` 结束时间 **< 片长**（半开区间会吃掉最后一帧）
- [ ] 动画**全部由 GSAP 驱动**，无 CSS keyframes 承担画面动效
- [ ] 无 `Date.now()` / `performance.now()` / 未播种 `Math.random()` / 渲染时联网
- [ ] 素材引用路径全部是工程内相对路径（无 `../`）
- [ ] 素材扩展名一致（改过 png→jpg 后，全仓库搜过引用）

## B. 校验

- [ ] `"$HF_BIN" check .` → **Lint 0 error**
- [ ] 布局：确认不是 `0 sample(s)`（那说明 lint 报错导致审计没跑）
- [ ] 布局 issue 要么修掉，要么**显式声明意图**（`data-layout-allow-overlap` / `-overflow` / `-occlusion`）
- [ ] Motion 0 error
- [ ] **对比度全部通过 WCAG AA**（注意：淡入淡出帧也会被采样）
- [ ] 唯一残留 warning 是 `nested_structure_needs_subcomposition`（Studio 展示用途，可接受）

## C. 渲染产物

- [ ] `render` 成功，日志无 `media_load_failed`
- [ ] `ffprobe` 复核：`width/height` 正确、`r_frame_rate` 正确、**`nb_frames == 片长 × fps`**、`duration` 正确
- [ ] **抽 MP4 的帧**（不是 snapshot）目视 4–6 处：无空帧、字幕整句居中不换行、特写对准控件
- [ ] 底部安全区检查：字幕与底部元素**完整可见**，未被 87px 视口裁掉
- [ ] 底边无横向色差接缝（逐行平均色，跨接缝差 ≤ 4/255）
- [ ] 片头 t≈0 无残留鼠标指针、无未完成状态

## D. 字幕与后期

- [ ] `cues.json` 是唯一数据源；画面字幕 / SRT / 总表**三者时间一致**
- [ ] `make-srt.mjs` 输出无警告（每句都塞得进 slot，无超片长）
- [ ] 语速符合口播（中文 4.3 字/秒，英文按字符计）
- [ ] SRT 与 txt 都随片交付
- [ ] 若无声：**主动告知需求方**（完播率影响）+ 提供配音/SRT 方案

## E. 交付包

- [ ] 视频按序命名（`01-`、`02-` …），一眼看出顺序
- [ ] 总览片（顺序拼接）+ 对比图（每支一帧）
- [ ] `README.md`：规格、素材来源、重渲方法、**版权提醒**
- [ ] 源工程可直接重渲（`env.sh` 齐备、依赖在工程内）
- [ ] 清理中间产物（抽帧临时图、`.DS_Store`、废弃组件）；大件（`.browsers` 等）不留

## F. 版权与合规

- [ ] 特写**避开**第三方画面（视频播放器、他人视频帧、平台 logo）
- [ ] 需要时对不可避免区域做了模糊/替换，或**在交付文档里显式说明**
- [ ] 产品截图来自**真实运行的产品**（不是编造），且不泄露密钥/隐私信息
- [ ] 封面同样遵守以上规则

## G. 封面（若交付）

- [ ] 主投流位用**平台实际展示比例**（B站信息流是 16:9）
- [ ] 缩到 ~300px 宽仍能读出核心信息
- [ ] 关键文字在安全区内（4:3 被裁 16:9 时不会切到字）
- [ ] 高亮环/标注**精准套住**目标控件
- [ ] 同时给 1x 与 2x 版本
